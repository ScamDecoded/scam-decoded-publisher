Privacy Policy

Application: Scam Decoded Publisher
Last updated: 24 July 2026

1. What this application is

Scam Decoded Publisher is a private, single-user internal tool. It is operated solely by the owner of the YouTube channel Scam Decoded and is used only to publish that owner's own original video content to that owner's own YouTube channel, and to review that channel's own performance statistics.

The application is not distributed, not offered to the public, and has no other users. It has no sign-up, no accounts, and no third-party access.

2. Who can use it

Only the channel owner. The application authenticates one Google Account — the owner's own — and operates exclusively on that account's own YouTube channel.

3. What data is accessed

Through the YouTube Data API and the YouTube Analytics API, and only after the owner grants consent via Google OAuth, the application accesses:

  • The owner's own video uploads and their metadata (title, description, tags, thumbnail, privacy status, scheduled publish time).
  • The owner's own channel performance statistics (views, watch time, audience retention, impressions, click-through rate, traffic sources).

The application does not access, collect, harvest, infer, derive, or store data about any other user, viewer, channel, or person. It does not access viewing history, location, browsing habits, or any personally identifiable information about anyone.

4. How data is stored

All data stays on the owner's own local computer. Specifically:

  • OAuth credentials and refresh tokens are stored in local files on that computer and are never transmitted to any third party.
  • Retrieved statistics are held locally for the sole purpose of displaying charts to the owner.
  • No data is stored on any server, uploaded to any database, shared with any third party, sold, or used for advertising.
  • Authorization credentials are excluded from version control and are not published anywhere.

5. Data retention and deletion

Locally cached YouTube API data is refreshed on each use and may be deleted at any time by deleting the local files. The owner can revoke the application's access at any time from the Google security settings page at https://myaccount.google.com/permissions. If access is revoked, all API data obtained under that authorization is deleted from the local machine within 30 calendar days, as required by the YouTube API Services Developer Policies.

6. Data sharing

None. No data obtained through YouTube API Services is shared with, sold to, or disclosed to any third party, and none is used to build profiles, train models, or produce derived metrics.

7. YouTube API Services

This application uses YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service. Google's Privacy Policy is available at https://policies.google.com/privacy.

Any change to this policy will be published on this page with an updated date.
