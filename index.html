Scam Decoded Publisher

A private, single-user publishing tool for the Scam Decoded YouTube channel.

This application uses YouTube API Services.

What this application does

Scam Decoded Publisher is an internal tool operated solely by the owner of the YouTube channel Scam Decoded. It runs on the owner's own computer and is used only to publish that owner's own original videos to that owner's own channel, and to review that channel's own performance statistics.

It is not distributed and is not offered to the public. It has no sign-up, no accounts, and no other users. It authenticates one Google Account — the owner's own — through Google OAuth, and operates exclusively on the channel that account owns. It does not access, collect, or store data about any other user, viewer, or channel.
